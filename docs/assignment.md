# Assignment: Sales Patriot on-site, Solicitation Browser (50 min, 2026-11-17)

Brief: pull daily DIBBS RFQs and help a vendor find the ones that matter. AI tools allowed. Deliverables: a git repo link and a short live demo.

## Requirements
1. [build] Pull data from DIBBS, at minimum the solicitation number and NSN.
2. [build] Browse the solicitations.
3. [build] Find the opportunities the vendor cares about (approach is ours).
4. [build] Open each row on its original DIBBS page.
5. [user] Push to a git repo and share the link.
6. [user] Give a short live demo and walkthrough.

Graded on: the find approach, problem-solving, judgment and taste (tradeoffs, what was left out), and product sense.
